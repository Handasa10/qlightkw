- 12–16 hashtags, Arabic + English, always `#كواليتي_لايت #الكويت #qualitylight`; no misleading or unrelated tags.
- Quiz videos: end with «اكتب A ولا B في الكومنت 👇» (the Instagram comment agent answers them).
- **TikTok**: first line + 1–2 value lines + «📍 حولي – شارع تونس» + 5–8 hashtags.
- **Threads**: 2–4 short lines, conversational, 0–2 hashtags.
- **YouTube Shorts**: title ≤ 70 chars (Arabic, with the hook), description = the TikTok text.
